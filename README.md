# The Deseret Alphabet Society

A TypeScript + Vite + React site for learning, reading, and transliterating the Deseret Alphabet.

Built in the same stack as [the-baybayin-project](https://github.com/cmckinney-59/the-baybayin-project), focused entirely on Deseret.

## Pages

- **About** — what the Deseret Alphabet is and how to read it
- **Resources** — historical documents, fonts, external links, and projects
- **Events** — upcoming gatherings and workshops
- **Transliterator** — live English ↔ Deseret transliteration

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
